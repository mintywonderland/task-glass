# Task Glass

モバイルで素早くタスクを記録し、カードのスワイプで状態を切り替えるタスク管理アプリです。Galaxy Z Fold などのスマートフォンを想定しています。

## 現在の実装

- タスクの追加・一覧・絞り込み（すべて／未着手／進行中／完了）
- タスクカードの左右スワイプとボタンによる状態変更
- タスクの削除、完了済みタスクの整理
- 日本語 UI、レスポンシブレイアウト、動きを減らす OS 設定への配慮
- ブラウザ内の `localStorage` への保存

## 現時点で未実装

- Google ログイン
- Cloudflare Workers / D1 への同期
- Workers AI
- 複数端末間の同期、バックアップ、アカウント削除フロー

現状は単一 HTML のフロントエンド試作です。ブラウザ内保存のため、同じブラウザ・端末内でのみデータが利用でき、ブラウザデータの消去などで失われる場合があります。重要なタスクの唯一の保存先としては使わないでください。

## 開発・確認

GitHub Actions の品質チェックは、HTML 内の JavaScript 構文と基本的な安全性・機能要件を確認します。自動チェックが成功しても、実機ブラウザでの操作確認やアクセシビリティ監査を代替するものではありません。

## セキュリティ方針

- パスワードを独自に保存・管理しない。
- API キー、OAuth クライアントシークレット、Cloudflare トークンをソースコードへコミットしない。
- Google 認証やサーバー同期を追加するまでは、アカウントや端末をまたぐ保護・同期があると表示しない。
- セキュリティ上の問題は公開 issue に機密情報を書かず、リポジトリ管理者へ非公開で報告する。
